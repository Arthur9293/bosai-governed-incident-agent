# 0C — AgentCore Controlled Deployment

## Objective

Deploy the already-proven BOSAI read-only Strands incident agent to Amazon Bedrock AgentCore
Runtime while preserving the 0A/0B authority boundary.

The deployment is a hackathon-development proof. It does not integrate production systems.

## Deployment architecture

`AgentCore Runtime (HTTP / CodeZip / eu-central-1)`
→ `BedrockAgentCoreApp`
→ `Strands Agent`
→ `Amazon Bedrock / Claude Sonnet 4.6`
→ read-only synthetic incident tools
→ `HUMAN_GO_REQUIRED`

## Runtime surface

The AgentCore endpoint accepts only two controlled prompt tokens:

- `BOSAI_0C_INCIDENT`
- `BOSAI_0C_AUTHORITY_PROBE`

The runtime does not accept an arbitrary execution command as authority. The Strands model has no
execution tool and no permit-issuance tool.

## Infrastructure boundary

Authorized by the 0C Human GO:

- AgentCore Runtime resources required by the AgentCore CLI;
- CDK / CloudFormation deployment infrastructure if required;
- IAM execution role(s) created by the development deployment;
- CodeZip staging assets in S3;
- CloudWatch / X-Ray observability resources generated by AgentCore.

Not authorized:

- production service mutation;
- production credentials or business data;
- AgentCore Memory;
- AgentCore Gateway;
- external API targets;
- autonomous permit issuance;
- final Devpost submission;
- merge without a separate Human GO.

The deployment must use a non-root AWS principal. Root credentials are explicitly rejected by the
deployment script before any 0C mutation.

## Evidence

The public evidence packet must not contain the AWS account ID or raw principal ARN. It records
SHA-256 bindings for those identifiers instead, plus sanitized runtime/deployment facts and the
actual AgentCore invocation responses.

Acceptance requires:

- local Ruff and 20 tests PASS;
- `agentcore validate` PASS;
- `agentcore deploy --dry-run` PASS;
- live AgentCore deployment PASS;
- live controlled incident invocation PASS;
- live authority probe PASS;
- `HUMAN_GO_REQUIRED` observed;
- synthetic runtime unchanged;
- no forbidden mutating tool observed;
- sanitized evidence packet produced;
- Draft PR + CI SUCCESS.
